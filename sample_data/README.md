# Sample data

Put your demonstration input files here before recording/screenshotting the demo:

- `sample_question_paper.pdf` — a digitally-generated or scanned question paper (multi-page, mixed numbering)
- `sample_scanned_page.jpg` — a low-quality/blurry scanned page (image upload path)
- `sample_answer_key.pdf` — a separate answer-key document (for the document-group / answer-association demo)
- `not_a_document.txt` — any non-pdf/image file, to demonstrate the invalid-upload rejection (item 10 in demo requirements)

The assignment's own PDF (the one you were given) works fine as
`sample_question_paper.pdf` if you don't have a better one on hand — it has
enough varied structure (numbered sections, weighted table) to exercise the
extraction path.
